# TXT to EPUB

一个在浏览器中将小说 TXT 文件转换为 EPUB 电子书的小工具。

当前版本为早期 `0.1.0`：适合转换结构较清晰的中文小说 TXT，并在下载前预览自动识别出的简介、部、卷和章节。

## 功能

- 支持 UTF-8、GBK / GB18030 文本，可自动尝试识别编码。
- 自动填写文件名作为书名，也可以手动设置书名和作者。
- 自动识别简介、部、卷和章节，并在网页中显示目录与正文预览。
- 支持常见标题格式，包括：
  - `第一卷`、`第一部` 及带标题的卷名；
  - `第一章`、`第一节`、`第一回`、`第一篇`；
  - `Chapter 1`；
  - `序章`、`楔子`、`前言`、`后记`、`尾声`；
  - `番外`、`番外篇`、带序号的番外及`完本感言`。
- 在 EPUB 导航目录中保留“部—卷—章”层级，缺少中间层级时保持原有阅读顺序。
- 生成 EPUB 3 文件并直接下载到本地。
- 没有可识别标题的 TXT 会作为单个“正文”章节处理。

## 使用方式

1. 打开网页并选择一个 `.txt` 文件。
2. 保持“自动检测”，或手动选择 TXT 的文本编码。
3. 确认书名和作者。
4. 点击“生成 EPUB”。
5. 查看识别出的目录和章节预览。
6. 点击“下载 EPUB”保存电子书。

如果正文乱码，请切换 UTF-8 或 GBK / GB18030 后重新生成。自动识别主要在这两类编码之间判断。

## 隐私说明

TXT 的读取、章节解析、EPUB 生成和文件下载都在当前浏览器中完成。项目目前没有上传文件的接口，也不需要将书籍内容发送到应用服务器。

和访问其他静态网站一样，托管平台仍可能记录常规访问数据，例如 IP 地址、请求时间、浏览器信息和网页资源请求；这些请求不包含所选择 TXT 的正文内容。

## 本地开发

需要 Node.js 20 或更高版本，以及 npm。

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

终端会显示本地访问地址，通常为 `http://localhost:5173`。

## 检查与构建

运行代码检查：

```bash
npm run lint
```

验证 TXT 解析和 EPUB 结构：

```bash
npm run verify:book-structure
```

生成生产构建：

```bash
npm run build
```

构建结果位于 `dist` 目录。可以使用以下命令在本地预览：

```bash
npm run preview
```

## 当前限制

- 章节划分依赖标题格式，排版特殊的 TXT 可能需要先整理标题。
- 当前不能在网页中手动拆分或拖动章节；支持修改标题、切换内容类型和向前合并。
- 文件在浏览器内存中处理，特别大的 TXT 会受到设备内存和浏览器性能限制。
- 当前不支持插图导入和自定义 EPUB 样式编辑器。

## 添加封面

选择 TXT 后，可在「封面（可选）」选择 JPG/PNG 图片（最大 10 MB），预览后点击「生成 EPUB」再下载。支持更换和移除封面；修改后需重新生成。封面保持原比例，图片与文本均在浏览器本地处理。

封面打包回归检查：`npm run verify:cover`。

## 生成预设与排版示例

「生成预设」同时决定 TXT 划分与 EPUB 美化。当前内置两个预设，均支持简介与部 → 卷 → 章三级结构、连续重复标题合并，以及独立部首页和卷首：

- 「欲语」：暗红印签章号与内敛的经典小说版式。
- 「微澜」：水墨青绿、舒展行距与留白构成的静读版式。
无需上传即可查看排版样张；样张默认展开，可切换简介、部首页、卷首和章节正文，展开下方说明可查看划分规则与示例原文。上传 TXT 后，生成与实际章节预览均使用所选预设；阅读器的字体和分页可能与浏览器不同。

扩展预设：在 `src/presets/` 添加独立模块，提供唯一 `id`、名称、描述、规则、`parse`、`css`、`renderSection`、`sampleText`，再加入 `index.js` 的 `PRESETS`。`renderSection` 输出带 `style.css` 链接的 XHTML，以供导出和内联预览共用。当前不提供用户自定义编辑器。

预设验证：`npm run verify:presets`。

## 章节纠错

首次生成 EPUB 后，在章节目录中选中一项，可修改标题、切换简介/部/卷/章类型，再点击「应用修改」。归属按阅读顺序自动更新：新部清空旧卷，新卷归入当前部；简介结束此前的部和卷。支持部下直接分章、无部或无卷的小说，简介位于顶层。
「合并到上一项」会把当前标题作为正文段落，连同内容追加到上一项；第一项不可向前合并。支持撤销最近 30 次已应用操作。
修改后需重新生成再下载；重新生成保留已应用的纠错结果。切换文件、编码或预设会清空修改；刷新页面不会保存修改。未应用的编辑不进入导出，切换章节会放弃未应用输入。

验证命令：`npm run verify:section-edit`。

三级结构验证：`npm run verify:hierarchy`，覆盖层级缺省、重名卷、修改类型与合并、EPUB 导航嵌套和阅读顺序。

桌面端的章节工作台保持在同一高度：左侧目录可单独滚动；选中章节后，右上为固定 230 px 高的纠错区、右下为占用剩余空间的排版预览，二者均可独立滚动。窄屏时依次堆叠，目录与纠错区保留各自的滚动范围。
